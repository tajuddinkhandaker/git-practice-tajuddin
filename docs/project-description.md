# Project Description

A simple Python utility library with basic math operations.

## Features

- `add(a, b)` - Return the sum of a and b
- `subtract(a, b)` - Return the difference of a and b (a - b)
- `multiply(a, b)` - Return the product of a and b
- `divide(a, b)` - Return the quotient of a divided by b (raises `ValueError` if b is 0)

## Usage

```python
from src.utils import add, subtract, multiply, divide

result = add(5, 3)       # Returns 8
result = subtract(10, 4) # Returns 6
result = multiply(3, 4)  # Returns 12
result = divide(20, 4)   # Returns 5.0
```

## Installation

Clone the repository and import the functions as shown above.
